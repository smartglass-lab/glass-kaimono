# グラス買い物メモ — Glass Kaimono

Meta Ray-Ban Display 用の買い物チェックリスト。文字入力なしでカタログから品目を選んでリストを作り、店内では視界の中のリストをタップでチェックオフ。両手がふさがる買い物中こそハンズフリーが効く、実用ツールです。

- **ライブURL**: https://glass-kaimono.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / 静的サイト）

## 特徴

- **文字入力ゼロでリスト作成** — 9カテゴリ・約80品目のカタログ（やさい／くだもの／にく・さかな／パン・たまご・乳／しゅしょく・めん／のみもの／ちょうみりょう／おかし／にちようひん）からタップで選ぶだけ
- **店内でタップしてチェックオフ** — チェックした品目は下に沈んで打ち消し線に。「のこり◯品」と進捗バーで残りがひと目でわかる
- **コンプリート演出** — 全部チェックすると🎉のコンプリート画面。買い物回数もカウント
- **localStorage 永続化** — リストとチェック状態は自動保存。ブラウザを閉じても買い物の途中から再開できる
- **オフライン動作** — API 不使用。店内の電波が弱くても動く
- すべてタップ＋D-padスライドだけで往復可能

## 操作方法

| 画面 | 操作 |
|------|------|
| ホーム | ↑↓で品目を選びタップでチェックON/OFF。「＋ ついか」でカタログへ、「⋯ そうさ」で一括操作へ |
| カテゴリえらび | ↑↓でカテゴリを選んでタップ。「←」でホームへ |
| 品目えらび | ↑↓←→で品目を選び、タップでリストに いれる／はずす。「✓ これでOK」でもどる |
| そうさ | チェックをぜんぶはずす／チェックずみをけす／リストをからにする |
| コンプリート画面 | 「リストをからにしてもどる」または「そのままもどる」 |
| PC確認用 | Escape でもどる（グラスの戻るジェスチャーは使用不可のため補助のみ） |

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E8%B2%B7%E3%81%84%E7%89%A9%E3%83%A1%E3%83%A2&appUrl=https%3A%2F%2Fglass-kaimono.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラス買い物メモ`、URL `https://glass-kaimono.vercel.app` を入力。
